# Beba Água

O Beba Água é um aplicativo simples de hidratação para quem passa o dia trabalhando e acaba esquecendo de beber água. Com lembretes e um botão para registrar rapidamente cada copo, o app mostra o progresso em relação à meta diária e ajuda a criar o hábito sem interromper a rotina.

Link do Projeto: https://crissbarichello.github.io/beba_agua/
